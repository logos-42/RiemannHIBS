## 一、"为什么是 1/2"的真正来源（非循环版本）

1/2 不是凭空出现在临界线定义里的。它的祖先链是：

```
ζ(s) = Σ 1/n^s
    → Mellin 变换核 t^{s/2}·dt/t      ← 指数 s/2，不是 s！
    → Γ(s/2) 出现
    → theta 级数 θ(t) = Σ e^{-πn²t}   ← 平方数 n²
    → θ(1/t) = √t·θ(t)                ← 变换公式里有 √t = t^{1/2}
    → 反射 s/2 ↦ (1−s)/2              ← 中点 = 1/2
```

**关键在 t^{s/2}：指数里的 /2 来自 n²（平方数）**。如果级数是 Σ 1/n^s，Mellin 变换的核是 t^{s/2}，那么函数方程把 s 和 1−s 配对，中点自然是 1/2。**1/2 = 平方数的平方根在 Mellin 层面的投影**——它是"二次型结构"的直接产物。

所以：**不动点在 1/2，是因为 ζ 是"平方级数"的 Mellin 变换。** 如果级数是 Σ 1/n^{s/k}（k 次幂），对称轴会变成 k/2。这就是"换半径"实验的钥匙。

## 二、换一个半径，对 zeta 意味着什么

在隐数坐标系里做思想实验：把不动圆半径从 √e 换成一般的 R（即对称轴从 Re(s)=1/2 换到 Re(s)=log R）。

这**不是自由选择**，它对应改变函数方程：

```
对称轴 Re(s)=a   ⟺   函数方程 s ↦ 2a−s   ⟺   w 平面圆 |w| = e^a
```

而函数方程的形式被级数的幂结构锁定。具体地：

- **a = 1/2**（我们的 ζ）：平方级数 Σ 1/n^s，Γ(s/2)，对称轴 1/2。
- **a = 1**：这是 Hurwitz zeta 方向。事实上 Hurwitz ζ(s,a) 关于 s↦1−s 也有对称性，但对称轴结构不同（与 a 无关地在 1/2）。
- **换 k**：级数 Σ 1/n^{s} 改成"k 次幂平均"，Γ(s/k)，对称轴 k/2，w 平面圆 |w| = e^{k/2}。

**所以"换半径"的真实含义是：换 zeta 的"幂结构"（k 值），而不是换坐标。** 半径 √e 之所以是 √e，因为 ζ 恰好是 k=2 的级数。这在经典复平面是看不到的联系——半径读数直接编码了级数的幂结构。**这是隐数坐标系给出的一条新信息链：半径 ↔ 幂次 ↔ Mellin 核指数。** 经典分析知道 Γ(s/2) 和 1/2 的关系，但"在 w 平面上半径=√e 就是幂结构 k=2 的读数"这个视角，确实是这个坐标系特有的。

## 三、不动圆为什么存在——它是自动的，不是奇迹

不动圆的存在不依赖 ζ 的任何特殊性质，它是**反演的代数必然**：

```
任何反演  w ↦ c/w   的不动集 = { |w|² = c } = 圆周 |w| = √c
```

反射 s↦1−s 在 w=e^s 下必然变成某个 c/w 形式（因为 e^{1−s} = e/e^s），所以不动圆**自动出现**。不是"圆恰好存在"，而是"**任何自对称函数在 w 平面都有不动圆**"。

真正的内容不是"圆存在"，而是**半径 c 的取值 = e，来自函数方程**。这让我更确信：在隐数坐标系里，**函数方程的代数内容（χ 公式）被压缩成一个数——半径**。ζ 的全部对称信息，在这个坐标系里就是一个圆。

## 一、把"长度锁定"写进覆盖空间的精确形式

在覆盖空间 E_θ（每点 ⟨r,θ⟩）上，ζ 的提升是单值的：

```
ζ̂(r,θ) = ζ(log r + iθ) = Σ (n+1)^{−log r} · e^{−iθ·log(n+1)}
```

拆开看**每一项的几何身份**：

- **模长** = (n+1)^{−log r} —— 由半径叶 r 决定；
- **相位** = −θ·log(n+1) —— 由方向 θ 和该自然数的角速度决定。

**在半径叶 r = √e（即 log r = 1/2）上**：

```
ζ̂(√e, θ) = Σ (n+1)^{−1/2} · e^{−iθ·log(n+1)}
```

这就是"长度锁定"的精确内容：**整片叶子上，所有向量的模长被锁死为 (n+1)^{−1/2}，唯一活着的自由度是相位 θ。** 而 θ 正是"方向"——隐数坐标系的一维。

## 二、缠绕：坐标系里"看得见"、经典里"看不见"的量

现在关键一步。让 θ 从 0 扫到 2π（在圆上走一圈）：

```
第 n 个向量转过的圈数 = log(n+1) / 2π
```

**每个自然数在圆上转的圈数不同**：n=1 转 log2/2π ≈ 0.11 圈，n=10 转 0.37 圈，n=10⁶ 转 2.2 圈。θ 每扫过一圈，第 n 个向量的相位就相对于第 m 个向量滑动 log((n+1)/(m+1)) 圈——**无穷多个不同转速的向量，其相对相位配置在 θ 的变化下持续改变**。

这就是"零点产生"在这个坐标系里的机制叙述：

> **零点 = 无穷多个不同转速的旋转向量在某个 θ 处恰好对齐（和为零）的时刻。由于相对相位随 θ 持续变化、遍历所有配置，这样的时刻必然出现。**

注意这一步没有用幅角原理，没有用 Hardy 的振荡积分——它用的是坐标系里**独有可见**的量：每项在圆上的缠绕圈数 log(n+1)/2π。经典复平面把 ζ(1/2+it) 写在直线上，看不到"每项转几圈"；在圆上，圈数是**每一个自然数的几何身份**。

## 三、为什么模长 n^{−1/2} 不是巧合——它是"锁定"的后果

经典视角下，ζ(1/2+it) 的级数在临界线上**条件收敛**（Σ n^{−1/2} 发散），这被当作"临界线很难"的证据。但在隐数坐标系里，这个"发散"有几何解释：

- 半径叶 r = √e 是**唯一一片使模长 (n+1)^{−log r} 处于"临界衰减"的叶**：
  - r > √e（log r > 1/2）：模长衰减快于 n^{−1/2}，级数绝对收敛，没有"对齐的必要"；
  - r < √e（log r < 1/2）：模长衰减慢于 n^{−1/2}，级数发散更严重；
  - **r = √e：模长恰为 n^{−1/2}，向量的"半径权重"与"相位遍历"达到平衡——零点的产生恰好需要这种平衡**（向量既不能太强地主导，也不能太弱地消失，才能通过相位对齐精确相消）。
