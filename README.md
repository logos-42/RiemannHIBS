# RiemannHIBS — Hidden-Number Arithmetic × the Riemann ζ/η Construction

**Lean 4 formalization**: construct the core functions of the Riemann
Hypothesis — the **Riemann zeta function ζ** and the **Dirichlet eta
function η** — with the **hidden-number arithmetic (隐数运算法则)** of the
HIBS framework (*Hidden-space Bridge System*, Liu & Xu), and formally verify
the algebraic skeleton in Lean 4.

Pure core Lean 4 (v4.28.0, **no mathlib**). Values are `Int`.

**中文版**: [README_zh-CN.md](README_zh-CN.md)

## 1. The three hidden components

The hidden layer `S = ⟨value, tag⟩` carries three kinds of hidden numbers,
each governed by one flow rule:

| Component | Definition | Flow rule | Role in the ζ/η description |
|-----------|-----------|-----------|------------------------------|
| **隐数 / Hidden number** | `Hidden` = ⟨val : Int, tag⟩ | A2a: `+`,`−` stay in the hidden layer (tag `S`) | ζ/η partial sums are hidden numbers — additive closure keeps them in the hidden layer |
| **隐虚数 / Hidden imaginary** | `hiddenImag b` = ⟨b, Tag.iR⟩ | A3: √ maps onto the imaginary branch (tag `iR`) | the imaginary part `t` of a critical-line point `1/2 + it` lives on the `iR` branch (`doubledEmbedding`) |
| **隐方数 / Hidden square-root** | `hSqrt h` = ⟨h.val, Tag.iR⟩ | A3: square root forces projection to iℝ | the square `t²` enters the `iR` branch via √ and projects to a pure imaginary ⟨0, t²⟩ (`sqrt_pure_imag`) |

The flow rules (HIBS axioms A2a / A2b / A3):

| Axiom | Rule | Tag |
|-------|------|-----|
| A2a | add / subtract stay in the hidden layer | `S` |
| A2b | multiply / divide force projection to ℝ | `R` |
| A3 | square root forces projection to iℝ | `iR` |

The asymmetry is the point: `±` stay hidden, `×÷` jump to ℝ, `√` jumps to iℝ.

> **Upstream note (2026-08-14, local sync only):** In the HIBS paper, model (4.5)
> and Example 4.3 carried a sign error in the square-root formula. The geometric
> convention (paper A3 / abstract / §5 calculation procedure) is
> **⟨+ ↦ iR⁻, ⟨− ↦ iR⁺** (positive half-axis to the negative imaginary axis,
> negative half-axis to the positive one) — the old (4.5) was inverted. Fixed in
> Lean_HIBS commit `cc08ceb`. This repo's `hSqrt` is the simplified
> value-preserving tag model (no half-axis structure, corresponds to the A3 tag
> clause, not the (4.5) value formula), so the fix does not affect it; the full
> A3 (sign-aware `hSqrtFull`) lives in Lean_HIBS `HIBS/Sqrt.lean`.

## 2. The construction (correspondence table)

| Hidden object | Rule | Tag | Mathematical object |
|---------------|------|-----|---------------------|
| `zetaTerm w n = hiddenProj (w n)` | A2b | `R` | the n-th term n^(−s) (a power, i.e. iterated multiplication) |
| `zetaSum w N` (built by `hAdd`) | A2a | `S` | ζ partial sum |
| `etaSum w N` (alternating signs) | A2a | `S` | η (Dirichlet) partial sum |
| `geomH p e` (geometric factor) | A2a | `S` | 1 + p + … + p^e |
| `hMul (geomH p a) (geomH q b)` | A2b | `R` | Euler-product factor — the product forces projection |
| `smoothH p q a b` (grid sum) | A2a | `S` | ζ sum over the integers generated by {p, q} |
| `doubledEmbedding t` (two-component) | — | `S` / `iR` | critical line 2s = 1 + 2it in integer coordinates |
| `hSqrt` on `t²` | A3 | `iR` | the imaginary direction emerges from the hidden square-root |

## 3. Proved theorems (all verified by Lean 4)

### Hidden-number arithmetic (`Hidden.lean`)
- `hiddenArithmetic_holds` — A2a ∧ A2b ∧ A3 hold in the labelled-pair model
- `add_flow_S / sub_flow_S / mul_flow_R / sqrt_flow_iR` — the four flow rules
- `π_nonInjective` — the projection is non-injective (A1): distinct hidden numbers can project to the same observable value

### ζ/η construction (`Zeta.lean`)
- `zetaTerm_tag_R` — every term is an `R`-branch object (multiplication forces projection)
- `zetaSum_tag_S / etaSum_tag_S` — partial sums stay in the hidden `S` branch (additive closure)
- `zetaSum_val / etaSum_val` — the value of a partial sum equals the sum of the term values
- `zetaSum_observable` — π(ζ partial sum) = ⟨sum, 0⟩

### Analytic-continuation skeleton (`Zeta.lean`) ★
```
eta_reconstructs_zeta :  (etaSum w (2M)).val = (zetaSum w (2M)).val − 2·evenSum w M
zeta_from_eta        :  (zetaSum w (2M)).val = (etaSum w (2M)).val + 2·evenSum w M
```
This is the finite algebraic skeleton of the classical identity
**η(s) = (1 − 2^(1−s))·ζ(s)**: the even-n terms of ζ sum to Σ(2k)^(−s) = 2^(−s)·ζ,
so 2·(even terms) = 2^(1−s)·ζ. The weight `w : Nat → Int` stands in for `n^(−s)`;
infinite-series convergence and analytic continuation are draft statements.

### Euler product (`Euler.lean`)
- `euler_product_expansion` — **generation theorem**: ∏_p(1 + p + … + p^a) = Σ_{p^i q^j} p^i q^j for arbitrary p, q, a, b ("multiplying all primes generates all integers", finite form)
- `euler_product_tag_R` — the Euler product is an `R`-branch object (A2b)
- `geomH_tag_S / smoothH_tag_S` — geometric factors and grid sums are `S`-branch
- `euler_zeta_observable_bridge` — **hidden bridge theorem**: π(Euler product) = π(ζ partial sum) — the `R`-branch and `S`-branch flows agree on the observable slice ℂ

### Critical line (`Riemann.lean`)
- `trivialZero` — trivial zeros s = 2k (negative even integers); witness: −2
- `criticalLine` — Re(s) = 1/2 in integer-doubled form: 2·Re(s) = 1
- `doubledEmbedding_observable` — the hidden embedding of 2s = 1 + 2it
- `sqrt_pure_imag` — the hidden square-root sends t² into the `iR` branch; its observable slice is the pure imaginary ⟨0, t²⟩

## 4. Draft statements (honestly unproved)

The following require real-analysis convergence, analytic continuation and the
functional equation — beyond the core-Lean integer model. They are declared as
`structure`s whose fields are never mistaken for proofs:

- `RiemannHypothesis` — every non-trivial zero of ζ lies on the critical line Re(s) = 1/2
- `HilbertPolya` — the imaginary parts of the non-trivial zeros form the spectrum of some self-adjoint operator

## 6. Limitations & outlook

- Values are `Int`: transcendental results (ζ(2) = π²/6), series convergence and
  analytic continuation require ℝ/ℂ analysis (a mathlib port is the natural next step).
- The full Riemann Hypothesis (infinitely many zeros, all on the critical line)
  is an open problem. The value of this project is at the **construction layer**:
  the hidden-number arithmetic gives the ζ/η series structure a precise algebraic
  skeleton, and makes the prime–integer bridge "Euler product = ζ series"
  verifiable.
